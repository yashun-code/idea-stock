# 💡 idea-stock

思いついたアイデアをすぐ書き留めて、**スマホとPCで同じメモを見られる**個人用メモアプリ。
書くのは一瞬、整理はAIまかせ。

- 開いたらすぐ入力欄。分類は考えず、思いついたまま書く
- 保存すると、AIが自動でタイトル・カテゴリ・タグを付ける（任意機能）
- ログインすれば、スマホでもPCでも同じメモが見える
- 音声入力対応。横スワイプで削除
- ビルド不要の単一ページPWA（HTML / CSS / JavaScript のみ）

## 自分用に作る

このアプリは**1人1環境**で使います。他人のメモは一切見えません。

自分用のコピーを作る手順は **[SETUP.md](SETUP.md)** にあります。
ターミナルは使いません。無料です。40分〜1時間ほどで完成します。

## 仕組み

| | |
|---|---|
| フロント | HTML / CSS / JavaScript（フレームワークなし、ビルド不要） |
| ホスティング | GitHub Pages |
| データ保存 | Supabase（Postgres）。行レベルセキュリティでログイン本人の行だけに制限 |
| ログイン | Supabase Auth（メール＋パスワード）。アプリ内に新規登録画面はない |
| AI整理 | Claude API（claude-haiku-4-5）。キーは端末ごとにローカル保存 |

技術的な詳細と設計上の注意は [CLAUDE.md](CLAUDE.md) を参照してください。

## 制限

- **オフライン非対応** — 圏外では保存できません
- **iPhoneでホーム画面に追加した場合、Safariとデータが分かれます**（詳細は SETUP.md）
